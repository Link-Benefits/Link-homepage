Estimates only, not a quote. Every % and $ change on this page is an estimate based on Priority Health's 2027 Small Group Relativity Grids (Priority Health agent login), the carrier's published percentage change in premium when a group switches from one plan to another. It is applied to the renewal premium you enter. The grid rounds to whole percents, so dollar amounts are approximate. Actual premiums come only from a Priority Health quote.

HMO and POS plans can be compared with each other: those changes (shown to one decimal) combine the HMO grid with each POS plan's filed 2027 POS-to-HMO rate factor, which runs from +7.8% to +9.6% by plan and is the same in every county. PPO plans compare only with PPO plans, because the PPO gap to HMO varies by region and plan. Plan design is in-network, single / family. Partners plans show Tier 1, with Tier 2 beneath where it differs. Coinsurance is the member's share.
