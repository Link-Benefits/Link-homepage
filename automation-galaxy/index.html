    How this view was made

    Built from files the estate monitor already writes every night, the auditors’ own log, and one read-only look at HubSpot’s record history for the day. Nothing was added to any workflow or script, and none of them know this page exists.

    The build opener places each star on the day it was created: workflow and form dates are exact, script dates come from each project and its code history, and Zap dates are estimated from their Zapier IDs.

    For stage moves and new deals, the workflows that light up are the ones that enroll on that change. For other record changes, the workflow shown is one of that record type. Policy and initiative records weren’t readable, so their workflows light up only when a deal hands work to them. Zapier keeps no history we can read, so a Zap lights up only when a HubSpot record shows it ran. No client, employee or deal information is on this page.
